% ====================== 1. INTRODUCTION = Goal & Motivation ===================
\def\introtext{%
{\large\linespread{0.65}\selectfont\parskip=0pt\black
{\bf We propose a human-centered UX evaluation framework leveraging webagents and human journey data. By aligning the webagents to human navigation behaviour, we enable scalable and faithful UX testing without iterative manual data collection.}\\[-4pt]
{\bf $\bullet$\ Human vs Agent trajectory:} Comparison reveals divergence and alignment invisible to automated testing.\\[-6pt]
%{\bf $\bullet$\ Scale UX evaluation:} Parallel agent execution reduces evaluation cycles from weeks to hours.\\[-6pt]
{\bf $\bullet$\ Scalable re-evaluation:} Re-usable human data steers agents and enables iterative design testing at scale.
}%
}


% ====================== 2. METHOD OVERVIEW = Users + Data + Workflow ==========
\def\methodtext{%
{\large\linespread{0.62}\selectfont\parskip=0pt\black
{\Large\bf Users}\\[-8pt]
{\bf $\bullet$\ UX designers \& Web developers:} The designer can use the tool to evaluate their design and human interaction patterns simulated by the aligned webagents.\\[-2pt]
{\Large\bf Data}\\[-8pt]
{\bf $\bullet$\ Human journeys:} We generate a testing link to be sent to the human testers, who explore the website accomplishing predefined tasks. Their website interaction is captured via a reverse-proxy tracking script.\\[-6pt]
{\bf $\bullet$\ Agent journeys:} Browser-Use agents with personalized system prompts solve the tasks and their navigation logs are stored.\\[-6pt]
{\bf $\bullet$\ Data-Types:} Clicks, Scrolls, Screenshots, Timestamps, URLs, DOM events\\[0pt]
}%
}

% ====================== 5. AGENT STEERING & EVALUATION =======================
\def\agentsteering{%
{\large\linespread{0.75}\selectfont\black
{\Large\bf Dashboard Analysis}\\[2pt]
{\bf $\bullet$\ User Interface:} Ranked usability issues anchored to screenshots and linked to visualisations.\\[0pt]
{\bf $\bullet$\ Aggregate Journeys:} Flow level path divergence.\\[0pt]
{\bf $\bullet$\ Heat Map \& Horizon:} Attentional differences and interaction intensity over time.\\[0pt]
{\bf $\bullet$\ Human vs.\ AI:} Statistical comparison of human and agent behaviour.\\[0pt]
{\bf $\bullet$\ Flow \& Sankey:} Navigation patterns and click-level path divergence.\\[4pt]
{\Large\bf Agent Steering \& HITL Re-evaluation}\\[2pt]
{\bf $\bullet$\ Prompt-injection steering:} Human trajectories injected as context to bias agents toward human-like navigation without fine-tuning.\\[2pt]
{\bf $\bullet$\ Re-evaluation:} Steered re-runs quantify alignment across versions without new recruitment.\\
}%
}


% ====================== 6. CONCLUSION = Discussion ===========================
\def\conclusiontext{%
{\large\linespread{0.75}\selectfont\black
Our framework demonstrates that webagents can be used to simulate human navigation behaviour. This enables scalable UX evaluation and iterative design testing without the need for repeated human data collection, which can be costly and time-consuming. While unaligned agents diverge, we manage with simple prompt-injection to steer agents toward realistic navigation patterns customized for each specific website.
LLM-powered agents steered by human trajectory priors serve as scalable proxies for UX evaluation. Prompt-injection alignment preserves behavioural fidelity while reducing manual testing cost. Future work targets VLM fine-tuning and automated action-point propagation.
}%
}
